Training scripts for RSED-Net
# Training

Run the training script[README.md](https://github.com/sainithin05/RSED-Net/blob/main/training/README.md "README.md"):


python train.py


The script supports:

* Checkpoint saving every 10 epochs
* Training resume from latest checkpoint
* Learning rate scheduling
* Final model export

Output files:



RSEDNet_weights.pth
