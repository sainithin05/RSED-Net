# Datasets

The proposed RSED-Net was trained and evaluated using the following datasets:

## Training Datasets

* LOL Dataset
* LOL-v2 Dataset

## Cross-Dataset Evaluation

* ExDark Dataset
* DICM Dataset

## Dataset Source

The datasets used in this work were obtained from publicly available sources and Kaggle repositories for research and evaluation purposes.



Please download the datasets from their respective official sources or Kaggle pages and comply with their original licenses and usage policies.
